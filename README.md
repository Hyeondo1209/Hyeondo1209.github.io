# Desk

김현도의 글, 논문 노트, 독서 노트를 A4 보고서처럼 놓아두는 사이트.
[Astro](https://astro.build)로 만들고 GitHub Pages로 올립니다. 주소: https://hyeondo1209.github.io

---

## 1. 글 올리기 (Word)

1. Word로 글을 써서 `desk\원고` 폴더에 저장합니다.
2. `desk` 폴더의 **올리기** 를 더블클릭합니다.
3. 브라우저에 미리보기가 열립니다. 확인하고 검은 창에 `y` 를 누르면 올라갑니다. `n` 을 누르면 아무것도 바뀌지 않습니다.
4. 1~2분 뒤 사이트에 반영됩니다.

글을 고치려면 같은 Word 파일을 고치고 다시 **올리기** 를 실행하면 됩니다. Word 원고는 내 컴퓨터에만 있고 인터넷에는 올라가지 않으니, 따로 백업해 두세요.

### 원고 맨 위에 쓸 수 있는 것 (모두 생략 가능, 제목보다 위에)

```
날짜: 2026-10-24          안 쓰면: 처음 올리는 글은 오늘, 이미 올린 글은 원래 날짜
인덱스: 철학, 독서         포스트잇 인덱스
주소: grgic-pyrrhonism    글 주소. 안 쓰면 파일 이름을 로마자로 바꿔서 씀
초안                      이 줄이 있으면 올리지 않음 (이미 올린 글이면 사이트에서 내림)
```

그 아래 **첫 문단이 제목**이고, 바로 이어지는 가운데 정렬 문단들은 부제가 됩니다.

### Word에서 쓴 것이 사이트에서는

| Word | 사이트 |
|---|---|
| 제목 1 / 제목 2 스타일 | 굵은 제목 / 밑줄 소제목 |
| 문단 전체를 굵게 (예: "가. 도덕") | 작은 굵은 제목 |
| 양쪽(또는 왼쪽)으로 들여쓴 문단 | 인용 |
| 내어쓰기 문단 (대화문, 1) 2) 항목, 참고문헌) | 줄 단위 묶음 |
| 각주 | `[1]` 각주 |
| 표 | 표 |
| **형광펜** | 노란 형광펜 (읽은 것에서 건진 곳) |
| **빨간 글자** | 빨간 펜 밑줄 (내 글에서 내 주장, 결론) |
| 굵게, 기울임, 링크, 그림 | 그대로 |
| 수식 편집기 | 수식 (흔한 구조만. 안 되면 원고에 `$E=mc^2$` 처럼 직접) |

## 2. 사이트를 직접 고칠 때 (디자인 등)

PowerShell에서:

```powershell
cd ~\desk
npm run dev      # 미리보기: http://localhost:4321 (끝낼 때 Ctrl + C)
```

고친 뒤 올리기:

```powershell
git add .
git commit -m "무엇을 바꿨는지"
git push
```

(올리기 를 더블클릭해도 바뀐 것이 함께 올라갑니다.)

### 마크다운으로 직접 쓰는 경우

`src/content/notes/` 에 `.md` 파일을 만들어도 됩니다. 형광펜은 `==이렇게==`, 빨간 펜은 `!!이렇게!!`, 각주는 `[^1]` / `[^1]: 내용` 으로 씁니다.

## 3. 고치고 싶을 때

| 무엇을 | 어디서 |
|---|---|
| 사이트 이름, 소개 | `src/site.config.ts` |
| 인덱스 색 | `src/site.config.ts` 의 `FLAG_COLORS` |
| 색, 글꼴, 간격 | `src/styles/global.css` 맨 위 `:root` |
| A4 나누기, 호치키스 조건 | `src/scripts/paginate.ts` |
| Word 변환 규칙 | `scripts/word.mjs` |

`example-` 로 시작하는 파일과 폴더는 예시입니다. 내 글을 넣고 나면 지워 주세요.
