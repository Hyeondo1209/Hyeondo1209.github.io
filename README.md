# Desk

김현도의 글, 논문 노트, 독서 노트를 A4 보고서처럼 놓아두는 사이트.
[Astro](https://astro.build)로 만들고 GitHub Pages로 올립니다. 주소: https://hyeondo1209.github.io

## 1. 글 올리기 (Word)

1. Word로 글을 써서 `desk\원고` 폴더에 저장합니다.
2. `desk` 폴더의 **올리기** 를 더블클릭합니다.
3. 브라우저에 미리보기가 열립니다. 필요하면 표시를 합니다(아래). 확인하고 미리보기 오른쪽의 **올리기** 를 누르면 올라갑니다. **올리지 않기** 를 누르면 사이트는 바뀌지 않습니다. (검은 창에 `y` / `n` 을 눌러도 같습니다.)
4. 1~2분 뒤 사이트에 반영됩니다. 다 끝나면 검은 창은 아무 키나 눌러 닫습니다.

글을 고치려면 같은 Word 파일을 고치고 다시 **올리기** 를 실행하면 됩니다. Word 원고와 표시(`원고\.표시`)는 내 컴퓨터에만 있고 인터넷에는 올라가지 않으니, 원고 폴더째 백업해 두세요.

### 미리보기에서 표시하기

미리보기에서는 글자를 드래그하면 도구 막대가 뜹니다: **형광펜 / 빨간 펜 / 연필 / 수정테이프 / 지우기**. 오른쪽 위의 날짜를 누르면 날짜도 바꿀 수 있습니다(입력하고 Enter).

- 본문 글자는 Word에서 고치고, 표시는 미리보기에서 합니다. 인쇄한 종이 위에 펜을 드는 것과 같습니다.
- 표시는 `원고\.표시` 폴더에 저장되고, Word 원고를 고쳐도 남습니다. 표시한 문장 자체를 고치면 올리기가 "붙을 곳을 잃었어요" 라고 알려줍니다.
- **수정테이프**로 가린 글자는 사이트 파일에 아예 들어가지 않습니다(학번 등). 화면에서 덮기만 하는 것이 아닙니다.
- Word에서 칠한 형광펜, 빨간 글자는 Word에서 지웁니다.
- 바뀐 원고가 없어도 올리기를 실행하면 표시만 할 수 있습니다.
- 공개 사이트에는 이 도구가 없습니다. 내 컴퓨터의 미리보기에서만 보입니다.

### 여백 메모 (Word 메모)

Word에서 글자를 고르고 **검토 → 새 메모** 로 남긴 메모는 사이트에서 오른쪽 여백의 메모가 됩니다.

- 메모가 붙은 문장 높이에 놓이고, 겹치면 아래로 차례차례 내려갑니다.
- 짧은 메모(90자 안쪽)는 **포스트잇**, 긴 메모는 **찢은 공책 종이**. 메모 맨 앞에 `[포스트잇]` 이나 `[공책]` 이라고 쓰면 직접 고를 수 있습니다(이 글자는 사이트에 안 나옵니다).
- 메모가 붙은 문장에는 옅은 점선 밑줄이 생기고, 메모나 문장에 마우스를 올리면 둘이 함께 밝아집니다.
- 메모 안의 굵게, 기울임, 형광펜도 그대로 갑니다. 메모에 쓴 내용도 공개되니, 혼자 보려던 메모는 올리기 전에 지우세요.

### 글 숨기기, 내리기

미리보기에서 글을 열면 오른쪽 여백에 **이 글은: 공개** 가 보입니다.

- **목록에서 숨기기**: 첫 화면과 글 목록에서 빠지고, 주소를 아는 사람만 열 수 있습니다(검색엔진에도 나오지 않게 표시). 비밀은 아닙니다.
- **사이트에서 내리기**: 사이트에서 없어집니다. Word 원고와 표시는 그대로 남아서 언제든 다시 올릴 수 있습니다.
- 숨기거나 내린 글은 미리보기의 첫 화면(또는 글 목록) 오른쪽 여백에 모여 있고, **다시 공개** 로 되돌립니다.
- 바꾼 뒤 **올리기** 를 눌러야 사이트에 반영됩니다. **올리지 않기** 를 누르면 숨기기·내리기는 취소됩니다.
- 원고 맨 위에 `초안` 이라고 써도 사이트에서 내려갑니다.
- 원고 파일을 지우기만 하면 사이트의 글은 그대로 남습니다(실수로 지워도 안전하도록). 먼저 내리고 나서 원고를 지우세요.
- 주의: 저장소가 공개라서, 내린 글도 GitHub 저장소의 지난 기록에는 남아 있습니다. 기록까지 지워야 하는 글은 Claude에게 따로 부탁하세요.

### 원고 맨 위에 쓸 수 있는 것 (모두 생략 가능, 제목보다 위에)

```
날짜: 2026-10-24          안 쓰면: 처음 올리는 글은 오늘, 이미 올린 글은 원래 날짜
인덱스: 철학, 독서         포스트잇 인덱스
주소: grgic-pyrrhonism    글 주소. 안 쓰면 파일 이름을 로마자로 바꿔서 씀
초안                      이 줄이 있으면 올리지 않음 (이미 올린 글이면 사이트에서 내림)
```

그 아래 **첫 문단이 제목**이고, 바로 이어지는 가운데 정렬 문단들은 부제가 됩니다.

### Word에서 쓴 것이 사이트에서는

| Word | 사이트 |
|---|---|
| 제목 1 / 제목 2 스타일 | 굵은 제목 / 밑줄 소제목 |
| 문단 전체를 굵게 (예: "가. 도덕") | 작은 굵은 제목 |
| 양쪽(또는 왼쪽)으로 들여쓴 문단 | 인용 |
| 내어쓰기 문단 (대화문, 1) 2) 항목, 참고문헌) | 줄 단위 묶음 |
| 각주 | `[1]` 각주 |
| 표 | 표 |
| **형광펜** | 노란 형광펜 (읽은 것에서 건진 곳) |
| **빨간 글자** | 빨간 펜 밑줄 (내 글에서 내 주장, 결론) |
| 굵게, 기울임, 링크, 그림 | 그대로 |
| 수식 편집기 | 수식 (흔한 구조만. 안 되면 원고에 `$E=mc^2$` 처럼 직접) |

## 2. 사이트를 직접 고칠 때 (디자인 등)

PowerShell에서:

```powershell
cd ~\desk
npm run dev      # 미리보기: http://localhost:4321 (끝낼 때 Ctrl + C)
```

고친 뒤 올리기:

```powershell
git add .
git commit -m "무엇을 바꿨는지"
git push
```

(올리기 를 더블클릭해도 바뀐 것이 함께 올라갑니다.)

### 마크다운으로 직접 쓰는 경우

`src/content/notes/` 에 `.md` 파일을 만들어도 됩니다. 형광펜은 `==이렇게==`, 빨간 펜은 `!!이렇게!!`, 각주는 `[^1]` / `[^1]: 내용` 으로 씁니다.

## 3. 고치고 싶을 때

| 무엇을 | 어디서 |
|---|---|
| 사이트 이름, 소개 | `src/site.config.ts` |
| 인덱스 색 | `src/site.config.ts` 의 `FLAG_COLORS` |
| 색, 글꼴, 간격 | `src/styles/global.css` 맨 위 `:root` |
| A4 나누기, 호치키스 조건 | `src/scripts/paginate.ts` |
| Word 변환 규칙 | `scripts/word.mjs` |
| 표시하기 도구 | `scripts/desk-editor.js` |
